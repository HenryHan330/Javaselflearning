## 2. 分布式基础概念

### 2.1 CAP

CAP 原理可以简单理解为：

- Consistency：一致性
- Availability：可用性
- Partition tolerance：分区容错性

常见结论：分布式系统中无法同时满足三者，通常要在两者之间取舍。

### 2.2 分布式锁

```java
// 伪代码：使用 Redis 实现分布式锁
String lockKey = "order:1001";
boolean ok = redis.setIfAbsent(lockKey, "1", 30);
if (ok) {
    try {
        // 处理业务
    } finally {
        redis.del(lockKey);
    }
}
```

## 3. 高并发常用方案

- 缓存：减少数据库压力
- 限流：控制流量
- 熔断：防止连锁故障
- 异步：解耦调用链

```java
// 伪代码：限流
if (rateLimiter.allow()) {
    doBusiness();
} else {
    throw new RuntimeException("请求过多，请稍后再试");
}
```

## 5. 学习重点

- 分布式不是“把单机东西复制一份”那么简单
- 要理解一致性、时序和故障场景
- 高并发重点在于“承载能力”和“降级保护”
