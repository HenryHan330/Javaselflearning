## 笔记写法建议

- **排版硬性要求：不要用 Markdown 表格**，一律一行一行写（短句 + 列表）。表格在 README 里显示很乱、也不好维护，写笔记时禁止使用。
- 先写“关键概念”：什么是它、为什么重要、常见误区
- 再写“面试/工作中的应用”：在项目里怎么用
- 再补代码示例：尽量用最小示例，方便回忆和复习
- 最后写“重点复盘”：3~5条总结，适合快速回看

## 学习原则

- 先会用，再理解原理
- 先写清楚，再做复杂项目
- 不追求一口气看完，而是每章都能输出自己的理解
- 代码示例要自己能跑，最好自己敲一遍
